Tree Generator

A guide to the controls in the settings panel

Use the panel in the upper-right corner to shape and style procedural trees. Most structure changes rebuild the tree; style changes update colors and leaves in place.

Navigation
Drag (mouse held)
Orbit the camera around the tree. Auto-rotation pauses while the button is held.
Scroll wheel
Zoom in and out.
Auto Rotate
Button beside Settings guide (lower-left). When on, the view slowly orbits on its own. Click to toggle off and keep the camera still.
Species & Archetype

Species

Chooses a tree type and loads its default size, crown, leaf, and color settings.

  • Oak — broad, rounded crown; lobed leaves
  • Pine — tall conical crown; needle clusters
  • Willow — drooping branches; long narrow leaves
  • Bonsai — compact, twisted form; dense small crown
  • Baobab — thick trunk, flat umbrella crown
  • Japanese Maple — delicate branching; maple-shaped leaves

Archetype

Sets the underlying branching architecture — how the tree grows in 3D space. Each archetype is named after a real tree architectural model and adjusts leader dominance, branch count, phyllotaxis (spiral angle), gravity response, and horizontal spreading.

  • Rauh — single dominant leader with lateral branches (typical oak-like form)
  • Massart — strong vertical leader, whorled branching (pine-like)
  • Troll — low, spreading, multi-stemmed habit
  • Leeuwenberg — suppressed leader, upward-angled branches
  • Champagnat — heavy gravity pull; branches sag downward (willow-like)
  • Scarrone — moderate leader with layered horizontal tiers

Changing species resets many values to that species' preset. Changing archetype updates architectural parameters only.

Growth
Speed
How fast branches and leaves animate into view (0.1–3×).
Play / Pause
Pause or resume the growth animation.
Regrow
Restart growth from the beginning and re-enable auto-rotation.
Structure

These settings control the procedural skeleton of the tree. Changes rebuild the entire tree.

Size
Depth
Maximum branching levels (3–8). Higher values produce more detail but denser geometry.
Length Ratio
How much shorter each new branch is compared to its parent (0.4–0.9). Lower = stubbier branches.
Bare Trunk
Fraction of the trunk with no side branches (0–1). Higher = longer clear trunk before branching begins.
Taper Curve
How branch radius shrinks along its length: linear, exponential, or stepped.

Branching
Branches
Number of child branches spawned at each node (1–6).
Branch Jitter
Random variation in branch count per node (0–3).
Phyllotaxis
Angular offset between successive branches around the stem (0–360°). 137.5° is the golden angle.
Leader Axis
How strongly the main trunk continues upward vs. splitting (−1 to 1). High = single tall leader.

Branch Shape
Angle
Base angle at which branches leave the parent (5–95°). Low = upward; high = horizontal or drooping.
Angle Spread
Random variation added to the branch angle (0–45°).
Curvature
How much branches bend along their length (0–1).
Variance
Overall randomness in branch length, angle, and placement (0–1).

Growth Bias
Gravity
Pull branches downward (−1) or upward (+1). Zero = no gravitational bias.
Gravity Mode
constant applies the same pull at every level; cumulative increases sag on higher-order branches.
Branch Horizontality
Encourages branches to spread outward horizontally (−1 to 1).
Branch Roll Snap
How strongly branches align to horizontal planes (0–1). Higher = flatter, more layered tiers.

Crown
Crown Shape
Constrains overall silhouette: none, cone, sphere, column, umbrella, or weeping.
Style

Visual appearance of bark and foliage. Color changes apply immediately; density and size rebuild leaves.

Trunk
Bark color at the base of branches.
Leaves
Leaf color tint.
Leaf Density
Number of leaf clusters per branch segment (2–25).
Leaf Size
Scale of individual leaf sprites (0.1–1).
Arrangement
How leaves attach to branches: alternate, opposite, whorled, fascicled (clusters), or radial.
Presets

Saved in your browser (localStorage). Includes species, seed, structure, style, and archetype — not prune edits.

Name
Enter a name for the preset you want to save.
Saved
Dropdown of presets stored on this device.
Save
Save the current settings under the name above. Overwrites if the name already exists.
Load
Apply the selected preset and rebuild the tree.
Delete
Remove the selected preset from localStorage.
Export JSON
Download the selected preset as a .json file for backup or sharing.
Import JSON
Load a preset file into localStorage, with an option to apply it immediately.
Tools
Prune Mode
Interactive editing. Click a branch to select it; click again to add a curve control point. Drag yellow handles to bend, orange to move the branch tip. Shift+click to chain selections. Delete or Backspace removes the selected branch or leaf.
Show Leaves
Toggle leaf visibility without rebuilding the tree.
New Seed
Generate a new random tree with the current settings and restart growth.
